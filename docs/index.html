Package and Sync Git Files to Telegram Instantly

A modern, developer-friendly CLI tool that packages modified, staged, or untracked files into a secure ZIP and uploads it directly to Telegram with a simple command.

Get Started View Source

Why use tg-sync?

Designed to be simple, fast, and secure for everyday developer workflows.

Auto Packaging

Automatically detects unstaged, staged, and untracked files, zipping them up while preserving your workspace's directory layout.

Debian Native

Package it as a native .deb package for easy system-wide distribution and automated dependency management via apt.

Interactive Setup

A smart configuration wizard runs automatically on your first launch to seamlessly configure your Telegram bot credentials.

Installation

Option 1

Debian / Ubuntu Package (Recommended)

Builds a system package that manages Python dependencies system-wide.

# 1. Build the Debian package
./build_deb.sh

# 2. Install it locally
sudo apt install ./tele-git_1.0.0_all.deb
Option 2

Manual CLI Setup

Runs within a local Python virtual environment.

# Clone repo
git clone https://github.com/bleu-fire/tele_git-.git
cd tele_git-

# Set up environment
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run setup wrapper script
./setup.sh

Configuration & Usage

Configuration

If credentials are not detected in your environment or configuration files, `tg-sync` will launch an interactive wizard automatically.

# Run setup wizard at any time
tg-sync config

# Verify the active version
tg-sync --version

CLI Usage

Run the command from anywhere inside your Git repository.

# Sync modified/untracked files
tg-sync

# Sync with a custom message description
tg-sync -m "feat: new CLI dashboard"

# Sync all tracked repository files
tg-sync --all
